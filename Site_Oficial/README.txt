REDE DOURADA - V3

Projeto escolar feito somente com HTML e CSS.

Páginas:
- index.html
- doacoes.html
- ongs.html
- rotas.html
- colaboradores.html
- sobre.html
- contato.html
- ong-casa-esperanca.html
- ong-novo-amanha.html
- ong-amigos-animais.html
- style.css

Não utiliza JavaScript, banco de dados ou frameworks.
Os dados das ONGs e endereços são demonstrativos.

Para abrir:
1. Extraia a pasta.
2. Abra index.html no navegador.

A estrutura usa elementos como header, nav, main, section, article e footer, uma organização recomendada para páginas HTML semânticas.
