SOBRE O PROJETO

Uma ideia simples: aproximar quem quer ajudar de quem precisa.

A Rede Dourada é um projeto criado para facilitar a organização de doações. O site apresenta informações sobre ONGs, sugestões de itens, pontos de entrega e formas de contato.

O objetivo é tornar o processo mais simples e incentivar a solidariedade na comunidade.

Tecnologias utilizadas

HTML

Responsável pela estrutura e conteúdo das páginas.

CSS

Responsável pelas cores, tamanhos, espaçamentos e layout.

Links

Usados para conectar as diferentes páginas do site.
